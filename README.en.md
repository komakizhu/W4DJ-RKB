# W4DJ RKB

[中文版](README.md)

A local tool for organizing, converting, and analyzing DJ music libraries.

![W4DJ RKB main interface](imgs/w4dj.png)

W4DJ RKB is based on and continues the development of [Slipstream-Max/w4dj](https://github.com/Slipstream-Max/w4dj), retaining the upstream project's focus on local scanning, incremental synchronization, and audio conversion.

## 1. Main features

- **Audio conversion and synchronization**: Supports NCM, MP3, FLAC, and WAV audio formats. Cleans downloaded music and converts it to offline formats supported by Rekordbox and CDJ/XDJ. Provides two independent source and output slots and accepts dropped song folders or individual tracks.
- **One-click DJ Set import**: Import a `.w4dj` playlist generated by [DJ Crate Digger](https://github.com/komakizhu/dj-crate-digger-skill), generate a QR code to import the playlist into NetEase Cloud Music with one scan, then convert the DJ Set with W4DJ and export an `.m3u8` playlist for Rekordbox. See the [step-by-step guide](https://github.com/komakizhu/dj-crate-digger/blob/main/docs/w4dj/README.md).
- **Metadata and artwork**: Preserves or restores titles, artists, albums, track numbers, Genre, lyrics, and artwork whenever possible. The NetEase database is read-only; output songs are managed by the independent `w4dj.sqlite3` database.
- **Interface and tutorials**: Supports Chinese/English and light/dark mode switching, with a tutorial that can be reopened at any time.
- **Safety and recovery**: Supports skipping, overwriting, and metadata-only updates. File naming handles illegal characters and conflicts. Output is written to a temporary file and safely committed. Conversion history, run sessions, and manually exported error reports are kept separate.
- **Desktop experience**: Provides a native macOS Tauri interface with visual progress. FFmpeg, analysis models, and user data are processed locally.
- **Music library Dashboard (in development)**: View converted songs in one place, see which files are available or no longer valid, and search, filter, sort, or clean up records in batches.
- **Enhanced audio analysis (in development)**: Automatically adds tempo, key, loudness, energy, danceability, Genre, and emotion information, with progress display, cancellation, and resume support.

## 2. How to import a playlist from the DJ Crate Digger Skill, prepare NetEase Cloud Music tracks, and export a Rekordbox playlist

[DJ Crate Digger](https://github.com/komakizhu/dj-crate-digger-skill) selects tracks and creates a `.w4dj` playlist file. W4DJ RKB receives that file and completes local track preparation, conversion, and playlist export. A `.w4dj` file stores only the playlist name, track order, official titles, and artist information; it does not contain audio files.

The complete flow is: [DJ Crate Digger](https://github.com/komakizhu/dj-crate-digger-skill) creates a `.w4dj` file → import it into W4DJ RKB → create a playlist in NetEase Cloud Music and download the tracks → W4DJ RKB converts the tracks and exports an `.m3u8` playlist → import it into Rekordbox.

See the [detailed handoff tutorial](https://github.com/komakizhu/dj-crate-digger/blob/main/docs/w4dj/README.md) between DJ Crate Digger and W4DJ RKB.

W4DJ RKB does not download or obtain copyrighted audio on the user's behalf; tracks must be prepared locally through lawful channels. The W4DJ RKB music library is based on actual output files and `w4dj.sqlite3`.
