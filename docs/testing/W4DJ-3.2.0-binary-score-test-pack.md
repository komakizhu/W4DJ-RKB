# W4DJ RKB 3.2.0 二元评分测试包

## 评分规则

每题只有三种状态：`是 = 1`、`否 = 0`、`待验证 = 不计分`。总分是所有已执行题目的通过数；未执行题目不能当作通过。正式发布前，以下任一硬门槛失败，直接判定“不具备发布条件”：原文件被修改/删除、输出不可播放、错误覆盖旧文件、转换失败无报告、应用无法启动、历史或缓存被静默覆盖、模型缺失导致普通转换失败。

自动化测试只能证明代码逻辑；真实网易云数据、Essentia 模型识别、Rekordbox 导入和 Windows 行为仍须人工测试。

## 一次性准备

在项目根目录运行：

```bash
bash scripts/generate-v3.2.0-test-fixtures.sh
bash scripts/validate-v3.2.0-test-fixtures.sh
```

默认输出到 `/private/tmp/W4DJ-RKB-v3.2.0-test-fixtures`，并生成同名 zip。夹具是合成音频，只用于验证流程、容器、标签、封面和错误处理，不能用于判断真实风格识别准确度。

需要用户提供的真实材料：

1. 3–5 个网易云本地普通 MP3/FLAC（不是 NCM），最好来自同一个实际下载目录，并保留同目录封面文件；请提供副本，不要提供唯一原件。
2. 6–10 首用于风格识别的真实歌曲，至少包含 3 首风格明显和 3 首跨风格歌曲。
3. 一次真实 Rekordbox 导入环境，用于把 XML 导入后检查字段。
4. 一台 Windows 电脑或虚拟机，用于验证“选择来源”和拖放。
5. 如果要测批量性能，准备 100 首和 500 首歌曲的副本；不需要把这些歌曲提交到仓库。
