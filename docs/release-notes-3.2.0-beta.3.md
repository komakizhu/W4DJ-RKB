# W4DJ RKB 3.2.0 beta-3 更新说明

## Breaking Changes

### 网易云数据库与元数据恢复

- 支持恢复歌曲名、歌手、专辑和本地封面。
- 支持自动发现和手动选择网易云数据库。
- 无标签文件只补全缺失信息，不覆盖可靠源标签。

### 歌单导入与导出

- `.w4dj` 是 DJ Crate Digger 与 W4DJ RKB 之间的歌单交接文件，保存歌单名称、曲目顺序、完整歌名和艺人信息，不包含音频。
- 导入 `.w4dj` 后，可通过二维码分页或拖入方式读取歌单；再将文字版歌单复制到网易云音乐的文字导入页面，完成匹配和本地下载。
- 下载完成后，W4DJ RKB 扫描并转换本地歌曲，只使用 W4DJ 独立歌曲库中的可用输出匹配歌单曲目和顺序。
- 导出统一生成“歌单文件夹/歌单名.m3u8”；可选择复制音频，方便把歌单整体移动到另一台电脑。
- 也可以只导出相对路径歌单，不复制音频；此时不要移动、重命名或删除原音频。
- `.w4dj` 不能直接导入 Rekordbox，必须先由 W4DJ 导出 `.m3u8`，再在 Rekordbox 中导入播放列表。
- W4DJ 不替用户获取版权音频；网易云自动匹配结果仍需人工确认版本是否正确。

## Changed

### 更可靠的转换与输出管理

- 扫描、转换和 FFmpeg 支持并发控制，最高 10 并发。
- 使用临时文件和原子提交，避免产生半成品输出。
- 支持转换历史、失败重试、继续未完成任务和磁盘空间检查。
