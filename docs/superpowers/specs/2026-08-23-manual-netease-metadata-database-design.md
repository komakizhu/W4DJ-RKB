# 手动选择网易云元数据数据库设计

**日期：** 2026-08-23<br>
**状态：** 待用户复核

## 目标

在任务 1“歌曲文件夹或单曲”标题右侧增加“选择网易云数据库”入口，与“扫描本地网易云文件夹”并列。该数据库只用于转换和分析元数据阶段的歌曲匹配、字段补全与本地封面恢复，不参与 Dashboard 歌曲枚举。

选择成功后只保存偏好并显示当前数据库文件名，不自动启动目录扫描、转换、增强分析或歌曲库刷新。用户可以更换数据库，也可以恢复自动定位。

## 数据边界

- 网易云数据库始终以 SQLite read-only 模式打开，不执行建表、迁移、写入、VACUUM、删除或重命名。
- 手动路径优先于自动定位；手动路径失效时允许回退自动定位，但界面和诊断必须显示警告，不自动删除已保存偏好。
- 只有文件存在、可以只读打开且包含受支持的网易云表时，才覆盖原有手动路径。选择失败保留此前有效值。
- `w4dj.sqlite3` 仍是 Dashboard 唯一权威数据源；`library-dashboard.sqlite3` 和网易云数据库都不得成为 Dashboard 候选歌曲来源。
- 远程 `picUrl` 只作为诊断信息，不联网下载封面。

## 界面与交互

任务 1 的来源标题行使用一个紧凑操作组：

- “扫描本地网易云文件夹”：保留现有自动定位音乐目录行为。
- “选择网易云数据库”：打开 SQLite 文件选择器。选择成功后显示数据库文件名，点击可更换。
- “恢复自动定位”：仅在存在手动路径时显示，清除手动偏好但不启动任何任务。

数据库操作进行时只禁用数据库相关按钮，不影响任务 2。成功状态显示“已选择数据库，开始转换或分析时使用”；失败显示可读错误。文件选择器取消不调用后端、不改变状态。

中英文文案都加入现有翻译表。窄窗口下操作组允许换行，不遮挡来源标题或路径控件。

## 后端接口

新增与 Dashboard 解耦的 camelCase DTO：

```ts
type NeteaseMetadataDatabaseStatus = {
  manualPath: string | null;
  effectivePath: string | null;
  source: 'manual' | 'automatic' | 'unavailable';
  loaded: boolean;
  recordCount: number;
  warning: string | null;
};
```

新增 Tauri 命令：

- `load_netease_metadata_database_status`
- `select_netease_metadata_database(path)`
- `clear_netease_metadata_database`

选择命令先完成只读 schema 校验和记录解析，再原子保存偏好。清除命令只清除手动路径。现有兼容命令可委托给同一内部实现，避免维护两套校验逻辑。

## 分析与转换数据流

每个转换或分析批次开始时读取一次偏好，创建一份不可变 `NeteaseMetadataResolver`，随后由该批次全部歌曲共享。批次执行过程中即使用户更换数据库，已启动批次仍使用原快照；下一批次才采用新选择。

匹配顺序沿用保守策略：精确来源路径、路径后缀、文件名与大小、文件名与身份字段。歧义匹配不得猜测。匹配成功后可使用数据库中的标题、歌手、专辑和 `meta` 本地封面数据补全输出；已有可靠输出标签或内嵌封面按现有优先级保留。

普通转换、仅更新元数据和增强分析结果写回必须使用同一批次解析器。任何数据库错误都只能形成逐曲或批次警告，不能删除输出文件、覆盖已有有效封面或阻止可独立完成的音频转换。

## 错误处理与诊断

状态和手动错误报告记录：手动路径、实际使用路径、来源类型、是否加载、记录数、匹配方式、歌曲/专辑 ID、封面来源及终止原因。路径只出现在用户主动导出的本地报告中；常规界面只显示文件名。

数据库不存在、schema 不支持或读取失败时，选择操作失败并保留旧值。已保存路径后来失效时尝试自动定位并显示警告。无匹配、歧义、只有远程封面和本地封面无效必须作为不同状态记录。

## 测试与验收

- 前端测试：按钮只出现在任务 1；选择器取消不调用后端；成功显示文件名；更换与恢复自动定位不触发扫描、转换、分析或 Dashboard 刷新；中英文和窄窗口布局正常。
- Rust 测试：DTO camelCase；旧偏好兼容；合法数据库持久化；错误 schema 不覆盖旧路径；手动路径优先；失效后自动回退并警告；数据库保持只读。
- 链路测试：普通转换、仅更新元数据和增强分析写回都收到同一批次解析器；歧义不匹配；已有封面不被较低优先级来源覆盖。
- 真实验收：选择用户网易云数据库，对实际 FLAC/MP3 输出执行元数据更新，使用 ExifTool 检查标题、歌手、专辑和封面，并从手动错误报告确认数据库路径、匹配方式和封面来源。
