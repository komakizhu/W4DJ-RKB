# W4DJ RKB 3.2.0 Six Bug Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `执行计划代理` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复直接转换、事务式输出、Rekordbox XML、WAV 元数据、网易云普通音频命名和 Windows 来源选择六类问题，并交付可直接打开的 Apple Silicon 测试 App。

**Architecture:** 转换任务只处理真正可执行的槽位；每首歌曲先写入同目录临时文件，完成音频、基础元数据和增强分析后才原子替换正式文件。Rekordbox、WAV、网易云命名和跨平台来源选择分别在现有模块内做最小扩展，不重构无关代码。

**Tech Stack:** Rust 2024、Tauri 2、TypeScript、Vitest、FFmpeg、ID3、RIFF INFO、Rekordbox XML。

## Global Constraints

- 当前版本保持 `3.2.0`，不修改 Release、标签或发布流程。
- 不修改增强模式整曲解码的内存策略，也不新增“验证文件可播放”扫描。
- 不自动提交或推送；只有用户说“定稿”后才允许 commit/push。
- 保留当前工作区所有既有未提交改动和未跟踪文件。
- 每个修复先写失败测试，再做最小实现；最后必须提供 Apple Silicon App 地址。

### Task 5: 网易云规则覆盖无标签普通 MP3/FLAC

**Interfaces:** 显式选择的 `NeteaseFilenameFormat` 在普通 MP3/FLAC 缺少有效标题和歌手时参与身份解析；有效内嵌标签仍优先。`HistoryEntry` 保存该设置，旧历史通过 `serde(default)` 兼容。

- [ ] 修改 `ensure_output_metadata_with_settings`：使用同一身份判断写入歌曲名和歌手，保证文件名与标签一致。
- [ ] 保持有效标签优先，避免把 SoundCloud 或已有正确标签的歌曲强行反转。
- [ ] 给 `HistoryEntry` 增加带默认值的网易云格式字段，创建历史和失败重试时保存/恢复该字段。
